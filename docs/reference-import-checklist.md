# Attorney Reference Import Checklist

Use this after exporting the attorney Google Doc into a local `.md` or `.txt` file.

1. Map each legal requirement to an intake step and field key.
2. Mark each field as:
   - `required by trustee`
   - `required for attorney strategy`
   - `optional context`
3. Add court-specific wording for the filing jurisdictions you support.
4. Identify any questions that must trigger attorney-only escalation.
5. Verify that each required document has a matching intake confirmation field.
6. Add final packet section ordering to match trustee expectations.
7. Run a legal review pass before production release.
